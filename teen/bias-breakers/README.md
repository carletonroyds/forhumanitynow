# Bias Breakers

A browser game for teens about cognitive biases. Players read everyday scenarios, name the bias at work, then pick the move that breaks it. The game ends with a timed lightning round, a collectible bias deck and a field mission.

## Play

Open `index.html` in any modern browser. Everything, including the artwork, is inside that one file.

## Publish with GitHub Pages

1. Upload `index.html` (and this README) to a GitHub repository.
2. In the repo, go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. Your game will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
