# 10 Social Media Antidotes

An interactive critical-thinking guide to ten common attention traps in social media and practical ways to counter them.

## Run Locally

**Prerequisite:** Node.js 22.13 or newer.

1. Install dependencies with `npm install`.
2. Start the development site with `npm run dev`.
3. Create a production build with `npm run build`.

The app does not require an API key. All ten illustrations are bundled locally for reliable loading.
